Start with a short main idea. Introduce every unfamiliar word and symbol before using it. Begin with everyday examples, then mathematical examples. Break worked examples into explicit steps: identify inputs, interpret the notation, apply the rule, calculate, state the result. Explain why each step is justified. Preserve mathematical precision while simplifying. Distinguish logical propositions from imperative instructions; qualify descriptions of programming syntax to the construct under discussion. Avoid sweeping claims about all languages. Present symbols once in clean notation rather than repeating fragmented rendered text. Explain the truth-value rule for implication without suggesting causation. State domains and hypotheses.
