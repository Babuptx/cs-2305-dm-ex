Source qualifications are made explicit. Page 279's unqualified polynomial statement needs a nonconstant hypothesis (constant prime polynomials are exceptions); the companion proves the precise claim that no nonconstant integer-coefficient polynomial is a positive prime for every positive integer input. The first Fermat formula needs a nonzero residue, including in the source page 297 remark. Page 299's failed-base-test reasoning is applied only with its required base conditions, so a prime dividing the base is not mislabeled composite. Page 300 includes both 0 and p−1 in its discrete-log exponent interval; these both produce residue 1 for a primitive root. The companion uses 0 ≤ e < p−1. Substitution uses fresh parameters consistently rather than repeating the source page 295's parameter-name slip. Record prime sizes and historical computational limits are not presented as current records.

The conjecture unit was checked against [Terence Tao's analytic prime number theory course introduction](https://terrytao.wordpress.com/2014/11/13/254a-announcement-analytic-prime-number-theory/) and [Oxford's Goldbach discussion](https://www.maths.ox.ac.uk/outreach/oxford-online-maths-club/episode-7), consulted November 17, 2026. These sources identify the even Goldbach, twin-prime, and quadratic-prime-value problems as open; the lesson attributes the context to the cited references and does not infer resolution from numerical examples or unreviewed claimed proofs. It distinguishes bounded prime gaps from gap exactly 2 and avoids time-sensitive largest-prime claims. References appear with the lesson as well.

All integer-value demonstrations use BigInt except the deliberately bounded Number sieve. Trial primality treats inputs below 2 as nonprime; factorization accepts positive integers and returns an empty list for 1. Gcd and extended gcd accept signed inputs and one zero, but exclude (0,0). Extended gcd returns g > 0 with s*a + t*b = g. The sieve's maximum limit is 1,000,000 for a modest array. Inverses require m > 1 and return null when the gcd is not 1. The linear solver accepts m > 0 and returns null or a compact base/period/count description, preserving all residue classes without allocating a huge list; modulus 1 and coefficient 0 are covered. CRT requires nonempty dense valid rows with moduli > 1 and checks pairwise coprimality through its inverses; rejecting noncoprime moduli is explicitly not a claim of inconsistency. The power table requires a verified prime at most 10,000 and checks the primitive-root condition; p = 2 is supported. Cross-unit helper dependencies are stated explicitly.
