The complete exposition of Rosen eighth edition §3.1.1–§3.1.6, printed pages 201–213, and §3.2.1–§3.2.5, printed pages 216–228, was read. Printed pages 208, 212, 224, and 228 were visually reviewed for pseudocode, interval assumptions, growth ordering, and lower-bound notation. The lessons use original explanations, traces, examples, checks, and code rather than reproducing textbook passages or its numbered exercise answers. Private extracts and page images are excluded from the repository and public build.

Section 3.1 covers algorithm specifications and properties, assignment and loop semantics, maximum finding, correctness and termination, linear and binary search, bubble and insertion sorts, naive string matching, greedy change, the denomination-specific optimality proof, interval scheduling and its exchange argument, and the halting contradiction. Eight executable JavaScript demonstrations validate their stated inputs. Search returns one-based positions with 0 for absence; scheduling returns zero-based original input indices. Empty inputs, duplicate keys, signed integers, overlapping matches, absent targets, leftover change, and touching intervals have explicit behavior. The binary search core follows the textbook's narrow-to-one-candidate variant and returns a first occurrence; its defensive full-array checks are correctly identified as additional linear work. Sorts preserve multiplicity and caller data. The left-scanning insertion variant is explicitly not stable on equal labeled keys. The displayed string matcher is restricted to binary text and nonempty binary patterns, avoiding unspecified Unicode indexing and empty-pattern semantics.

The scheduling lesson sorts complete interval records by finish time. It does not adopt the source procedure header's simultaneous sorted-start and sorted-finish assumption. Strictly positive durations, paired endpoints, and the count objective are explicit. Exchange reasoning supports all input sizes; exhaustive tiny schedules are additional checks. The coin proof establishes all denomination counts using equal-value replacements for the mathematical system {25, 10, 5, 1}; it is not generalized to arbitrary denominations or actual currency availability. The halting proof assumes a total universal decider and treats program descriptions as data. No nonterminating demonstration is executed. Particular decidable cases and partial checkers are distinguished from a universal solution.

Section 3.2 covers asymptotic quantifier order, positive witnesses, thresholds, absolute values, non-tight upper bounds, transitivity, disproofs for arbitrary witnesses, signed polynomials, logarithm bases and parentheses, the standard growth hierarchy, factorial/log-factorial estimates, sum/product rules, cancellation, compound estimates, Omega, Theta, the general leading-term lower bound, and tail bounds for sums. Integer versus real domains and fixed parameters are stated. The hierarchy is a theorem-based eventual comparison rather than a claim that sample values prove limits. The lesson does not conflate Big-O with worst case or Omega with best case, or assume hardware makes every primitive operation constant-cost. The source's stray equality between different growth functions in its page 224 ordering example is not reproduced. The sum argument retains the endpoint ceil(n/2) explicitly, avoiding a mismatch between the source prose and displayed sum.

General invariant, exchange, halting, asymptotic, and polynomial arguments were reviewed separately; finite tests do not establish unbounded claims.
